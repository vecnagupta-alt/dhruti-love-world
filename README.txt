DHRUTI LOVE WEBSITE — VERSION 3

Included:
- Cinematic intro screen with “Tap to enter our little world”
- Four clickable love letters
- Photo section using your supplied photo
- Floating hearts and romantic night-sky styling
- Music controls and a YouTube search button for “Jab Tak” by Armaan Malik

PUBLISH / UPDATE ON GITHUB PAGES
1. Download and extract this ZIP.
2. Open your existing GitHub repository in the browser.
3. Open index.html, tap the pencil/Edit button, replace its contents with this package's index.html, and commit the change.
4. Keep your existing assets/our-memory.jpg file. If needed, upload the included assets/our-memory.jpg into the repository's assets folder.
5. Wait a minute or two, then refresh your live GitHub Pages site.

BACKGROUND MUSIC
This package does not include copyrighted music. To enable the in-page music toggle, add an audio file you are legally allowed to use and name it exactly:
assets/background-music.mp3
Upload it inside the repository's assets folder. The browser still requires a user tap before playback. Otherwise, use the “Play Jab Tak on YouTube” button; the song opens on YouTube.

Your existing GitHub Pages address should stay the same if you update the same repository.
